# יומן התפתחות תינוק 👶

אפליקציית ווב בעברית למעקב אחרי ההתפתחות של התינוק/ת בשנה הראשונה — גרסה דיגיטלית וידידותית של יומן ההתפתחות המודפס.

> כל רגע קטן הוא הישג גדול

**הכול נשמר במכשיר שלכם בלבד.** אין שרת, אין חשבון ואין העלאה לאינטרנט — הטקסטים, התמונות וההקלטות נשמרים ב-IndexedDB
של הדפדפן, ואפשר לייצא אותם לקובץ גיבוי בכל רגע.

---

## מה יש באפליקציה

| מסך | מה הוא עושה |
|-----|-------------|
| **בית** | גיל מעודכן, אחוז מילוי היומן, קיצור לחודש הנוכחי ורשימת ההישגים האחרונים |
| **12 עמודים חודשיים** | ארבעה תחומי התפתחות, יכולות חדשות עם תאריך, רגע מיוחד, תמונה והקלטה |
| **אבני דרך ראשונות** | 18 "פעם ראשונה" מהיומן המקורי, עם תאריך, הערה וטווח גילאים מקובל |
| **מעקב גדילה** | טבלת משקל/אורך/היקף ראש לפי גיל, ושלוש עקומות גדילה אישיות |
| **ציר זמן** | כל ההישגים המתוארכים במקום אחד, מהחדש לישן, עם סינון לפי סוג |
| **פרטי התינוק/ת** | עמוד השער: שם, תאריך לידה, משקל ואורך בלידה, כותב/ת היומן ותמונה ראשונה |
| **איך משתמשים** | הסבר על ארבעת התחומים והטיפים מהיומן המקורי |
| **גיבוי והדפסה** | ייצוא/ייבוא קובץ גיבוי, מחיקת נתונים, והדפסת היומן המלא כ-PDF |

### ארבעת תחומי ההתפתחות

בכל חודש מופיעים אותם ארבעה תחומים מהיומן המקורי:

- 🤲 **מוטורי גס ועדין** — תנועה, שיווי משקל, אחיזה וזריזות ידיים
- 💬 **שפה ותקשורת** — הברות, מילים, הבנה ותגובה לקול
- 💞 **חברתי-רגשי** — חיוך, קשר עין, שעשועים וקשר עם הסביבה
- 🧩 **קוגניטיבי וחשיבה** — סקרנות, משחק, זיכרון ופתרון בעיות

### מה נוסף מעבר ליומן המודפס

- **גיל וטווחי תאריכים מחושבים לבד** מתאריך הלידה — כל עמוד חודשי יודע לאיזו תקופה הוא שייך, והאפליקציה מסמנת את
  החודש הנוכחי.
- **דוגמאות עדינות לכל תחום בכל חודש** — מופיעות כטקסט רקע בשדה, כהשראה בלבד ולא כרשימת ציפיות.
- **תמונה והקלטה קצרה לכל חודש** — התמונות מוקטנות ונדחסות אוטומטית כדי לחסוך מקום.
- **עקומות גדילה אישיות** — גרף נפרד לכל מדד (משקל, אורך, היקף ראש), עם ציר משלו.
- **מצב לילה** — לרגעים שבהם ממלאים את היומן בשלוש לפנות בוקר.
- **עובד כאפליקציה בטלפון** — אפשר להוסיף למסך הבית ולקבל מסך מלא, אייקון ועבודה גם בלי אינטרנט.
- **תצוגת הדפסה** — היומן המלא, עמוד לכל חודש, מוכן לשמירה כ-PDF. מודפסים רק עמודים שיש בהם תוכן.
- **שמירה אוטומטית** — מה שכותבים נשמר לבד, בלי כפתור שמירה.

> ⚠️ היומן נועד לתיעוד ולשמחה, לא לאבחון או להשוואה. טווחי הגילאים המוצגים הם כיוון כללי בלבד — אם משהו בהתפתחות
> מטריד אתכם, הכתובת הנכונה היא טיפת חלב או רופא/ת הילדים.

## שימוש מהטלפון (אייפון ואנדרואיד)

האפליקציה בנויה לעדכון מהטלפון תוך כדי היום, ומותקנת כ-PWA — בלי חנות אפליקציות.

**אייפון (Safari):** כפתור השיתוף ⬆️ → "הוספה למסך הבית".

זה לא רק נוח: Safari מוחק אחסון מקומי (IndexedDB/localStorage) של אתרים שלא ביקרו בהם כשבוע, ואתרים שנוספו למסך הבית
לא נכללים בניקוי הזה. האפליקציה מציגה על כך הודעה ידידותית לגולשי אייפון, ובכל מקרה כדאי לייצא גיבוי מדי פעם.

**אנדרואיד (Chrome):** תפריט ⋮ → "התקנת אפליקציה".

מה נעשה במיוחד עבור מסכי מגע:

| נושא | מה נעשה |
|------|---------|
| זום אוטומטי של Safari | כל שדות הקלט ב-16px במסכי מגע, כדי ש-Safari לא יזום בכל לחיצה על שדה |
| יעדי נגיעה | כפתורים ואייקונים בגובה 44px (36px לכפתורים קטנים) |
| מגרעת ופינות | `viewport-fit=cover` יחד עם `env(safe-area-inset-*)` בכותרת ובתוכן |
| גובה מסך | `100dvh` — לא "קופץ" עם הסרגלים הנעלמים של Safari |
| שמירת גיבוי | `navigator.share` עם קובץ — באייפון נפתח תפריט השיתוף לשמירה ב"קבצים"/iCloud |
| תמונות | בחירה מגליל התמונות או צילום במקום, עם הקטנה ודחיסה לפני השמירה |
| עבודה בלי רשת | service worker שמגיש מהמטמון ומעדכן ברקע |

## הרצה מקומית

```bash
npm install
npm run dev       # פיתוח על http://localhost:5173
```

פקודות נוספות:

```bash
npm run build     # בדיקת טיפוסים + בנייה לפרודקשן אל dist/
npm run preview   # הצגת הבנייה מקומית
npm test          # הרצת הבדיקות (vitest)
npm run typecheck # בדיקת טיפוסים בלבד
```

## פריסה

הפרויקט נבנה כאתר סטטי לגמרי, ואפשר להעלות את תיקיית `dist/` לכל שירות אחסון סטטי.
ה-workflow שב-`.github/workflows/deploy.yml` בונה ומפרסם אוטומטית ל-GitHub Pages בכל דחיפה ל-`main`
(צריך להפעיל פעם אחת: **Settings → Pages → Source: GitHub Actions**).

הבנייה משתמשת בנתיבים יחסיים (`base: './'`), כך שהאתר עובד גם תחת נתיב של פרויקט ב-GitHub Pages וגם בדומיין משלו.

## מבנה הקוד

```
src/
├── data/          הגדרות התוכן מהיומן: תחומים, חודשים, אבני דרך, שורות גדילה, דוגמאות
├── lib/           לוגיקה טהורה: תאריכים וגיל, אחסון, מדיה, התקדמות, גיבוי, ניתוב
├── store/         JournalContext — מצב היומן ושמירה אוטומטית מושהית
├── components/    רכיבי ממשק: מעטפת, שדות, בחירת מדיה, גרף גדילה
├── pages/         המסכים
├── styles/        מערכת העיצוב (global.css) וסגנונות ההדפסה (print.css)
└── tests/         בדיקות vitest ללוגיקה
```

### טכנולוגיות

React 18 + TypeScript + Vite. ללא ספריות ניהול מצב, ניתוב או UI — הניתוב מבוסס hash (40 שורות), המצב יושב ב-Context,
והעיצוב הוא CSS עם משתנים. שתי תלויות ריצה בסך הכול: `react` ו-`react-dom`.

### אחסון

| מה | איפה |
|----|------|
| היומן כולו (כולל תמונות והקלטות) | IndexedDB, מסד `baby-journal` |
| גיבוי אם IndexedDB חסום | localStorage |
| העדפת מצב יום/לילה | localStorage |

ניקוי נתוני האתר בדפדפן ימחק גם את היומן — לכן כדאי לייצא גיבוי מדי פעם.

## נגישות

- כל האפליקציה בעברית, `dir="rtl"`, וקבצי הגרפים עטופים ב-`dir="ltr"` כדי שהצירים יישארו קריאים.
- כל שדה נושא תווית, לכפתורי הסימון יש `aria-pressed`, ולסרגלי ההתקדמות `role="progressbar"`.
- צבעי הגרפים נבדקו לניגודיות ולהבחנה בעיוורון צבעים בשני המצבים, וכל גרף מלווה בטבלה מלאה של אותם נתונים.
- קישור "דילוג לתוכן", מיקוד נראה לעין, וכיבוד `prefers-reduced-motion`.
